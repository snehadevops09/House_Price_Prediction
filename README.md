## 📌 Project Overview
This project predicts house prices using **Linear Regression** based on features like area, bedrooms, bathrooms, and other property details.  
It demonstrates a complete **machine learning workflow** from data preprocessing to model evaluation. 

---

## 🎯 Objectives
- Analyze housing dataset to find key price factors  
- Perform data preprocessing and encoding  
- Train Linear Regression model  
- Evaluate model using R² and MSE  
- Visualize insights using graphs  

---

## 📊 Dataset Description
The dataset includes:

- **Price** → Target variable  
- **Area** → Size of house  
- **Bedrooms, Bathrooms, Stories** → Structural features  
- **Mainroad, Guestroom, Basement, Airconditioning, Prefarea** → Binary features  
- **Parking** → Parking capacity  
- **Furnishing Status** → Categorical feature  

---

## ⚙️ Project Workflow

1. Data Cleaning & Preprocessing  
2. Feature Encoding (Yes/No → 1/0, One-hot encoding)  
3. Exploratory Data Analysis (Heatmap, Graphs)  
4. Train-Test Split  
5. Model Training (Linear Regression)  
6. Prediction & Evaluation  
7. Visualization (Actual vs Predicted)  

---

## 📈 Results & Insights

- **Area** has the strongest impact on house price  
- **Bathrooms and parking** show moderate influence  
- Model performs well based on R² score  
- Predictions closely match actual values
